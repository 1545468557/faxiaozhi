# 法律分析与论证框架（口径，不含法条原文）

> 本文件只放**口径与规则**。法条与案例只能通过检索工具从权威数据源取得（PRD 2.1）。

## 一、类案研究的四步

1. **识别争点**：把用户议题拆成可检索的法律问题（不超过 3 个），并标明每个问题需要的规范类型。
2. **确定规范**：每个争点对应的规范由检索工具给出；**不得用记忆补齐条文**。
3. **提取事实**：只提取材料中真实出现的事实要素；提取不到的字段明确写「未提取到」。
4. **归纳结论**：结论只描述本次确认样本范围内的情况，并逐条给出引用。

## 二、要素分解（与 element-spec 对应）

- 事实（facts）：与争点相关的时间、主体、行为、结果。
- 主张（claim）：当事人提出的请求与理由。
- 争点（issues）：法院归纳或裁判文书中实际讨论的问题。
- 裁判理由（holding）：法院对争点给出的理由与规范适用。
- 结果（result）：裁判主文。

## 三、论证质量标准

- 每条结论必须能回查到具体来源的原文；
- 结论之间不得互相矛盾而不作说明；
- 出现相反观点时必须单列，不得合并为「主流观点」。

## 四、禁止事项

- 不得把「未检出」写成「不存在」；
- 不得把单一样本的做法写成通行规则；
- 不得以「据统计」等无来源表述修饰结论。
