# 观点归类规则

## 三档归类

| 归类 | 判定 |
| --- | --- |
| 主流 | 本次确认样本中持该立场的数量最多，且至少占样本的三分之二 |
| 相反 | 与主流立场方向相反的裁判理由 |
| 少数 | 数量少于三分之一或原文表述模糊的其他立场 |

## 强制口径

- 分布数字**由代码计算**，模型只解释，不得自行给出比例；
- 每次描述分布必须带分母：写成「本次确认样本 N 篇中 n 篇…」；
- 必须附范围声明：**仅描述本次样本，不代表全国裁判比例**；
- **未检出相反观点 ≠ 不存在相反裁判**，必须在局限中说明。

## 相反观点主动检索

在综合阶段之前，应当针对主流立场构造一次反向检索式；若反向检索返回为空，
必须区分「未找到匹配」与「接口失败」两种情况写进局限，不得默认为「不存在」。
