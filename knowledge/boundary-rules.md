# 表达边界规则

> 与 `app/gates/expression.py` 的正则表一一对应；可在 `config.yaml: policy.forbidden_patterns` 追加。

## 五类越界表述

| 类别 | 例子 | 改写口径 |
| --- | --- | --- |
| 总体化推断 | 「全国法院普遍支持…」 | 「本次确认样本 N 篇中有 n 篇…」 |
| 伪指标 | 「胜诉率 78%」 | 删除该表述，只描述样本内结论方向 |
| 无来源百分比 | 「高达 90% 的案件…」 | 给出分母与来源，或删除 |
| 确定性承诺 | 「可以确定该条无效」 | 「本次样本中的裁判理由倾向于…」 |
| 存在性断言 | 「该案例不存在」 | 「本次检索条件与数据源范围内未找到匹配」 |

## 处理方式

- 出现在结论中：该条结论**降级为「依据缺口」**，不作为结论输出；
- 出现在文档中：**导出被拒绝**，并指出命中的具体片段；
- 允许讨论、允许修改，但**不允许交付**。
