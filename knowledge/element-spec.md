# 单案要素提炼口径

## 提取规则

1. 只依据给定原文，不引入外部知识。
2. 五要素中任一要素在原文中找不到对应内容时，**必须写入 `missing_fields`**，不得猜测、不得留空。
3. `basis` 中的每一段引文必须与原文**逐字一致**（标点差异可容错，改写视为编造）。
4. `stance` 只能取 `support` / `oppose` / `other` / `unknown`：
   - `support`：裁判理由支持用户议题所指向的立场；
   - `oppose`：裁判理由明确采取相反立场；
   - `other`：讨论到该争点但立场不同或未明确表态；
   - `unknown`：原文没有涉及该争点。
5. 一案一条记录，`case_id` 使用系统给出的来源编号。

## 常见瑕疵（由门禁拦截）

- 引用原文与权威原文不一致 → 门禁 R5 拦截；
- 引用标识为空或不一致 → 门禁 R4 拦截；
- 效力状态未核对 → 门禁 R6 拦截。
