# 法小智合同审查：独立交互预览

启动：在本目录执行 `python3 -m http.server 5187 --bind 127.0.0.1`，访问 http://127.0.0.1:5187/。

## 范围

仅静态预览，未更改正式应用，未接后端或模型，无网络文件上传。文件选择只读取文件名及大小，不解析正文。所有审查意见来自固定的虚构合同，按甲方立场演示。选择其他立场仅展示表单状态，不假称生成对应结果。页面及导出的报告均标识示例。

## 设计

- 颜色：深绿 #17675C、墨绿 #173D37、浅灰绿 #F5F7F6、纸白 #FFFFFF、边线 #DCE5E1、风险红 #AA4E3E。
- 字体：界面使用系统中文无衬线；合同与报告标题使用系统宋体。保持标签易读，正文左对齐。
- 四步导航：放入合同 → 确认要求 → 审查内容 → 生成报告。进度属于第三步。
- 上传页提供格式与大小提示、拖放与按钮双入口、示例体验。
- 审查页原文与建议联动，支持筛选、编辑、采纳、暂不采纳与撤销。
- 报告包含全部事项与处理状态，可开关原文及说明，下载独立 HTML 或通过打印保存 PDF。
- 移动端改为上下布局，原文区可滚动；支持键盘焦点与减少动态效果偏好。

## 正式接入前要确认

1. 是否采用本布局与分步流程。
2. 后端解析应返回真实主体名称、条款位置和文件核验结果。
3. 真实进度不可直接使用预览计时器；风险和依据状态必须来自后端。
4. 修改采纳、撤销和报告版本需要后端持久化，预览状态仅在当前页面内存中，刷新会清空。
5. PDF/Word 正式导出接现有服务；此处仅提供示例 HTML 和浏览器打印。

## 本次验证

- JavaScript 语法检查通过。
- 浏览器走通示例选择、立场确认、模拟进度、风险结果、编辑建议、采纳、生成报告和下载操作。
- 报告显示采纳记录与手动修改的文字。
- 1440px 上传页，以及 390px 审查页、报告页无横向内容溢出。
- 没有调用正式接口、付费模型或上传用户合同。浏览器打印入口已提供，未执行真实打印。
