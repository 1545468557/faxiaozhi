# 类案检索全流程设计预览

独立静态预览。未修改正式前端、后端或接口；未调用付费服务。

## 打开
在此目录运行 `python3 -m http.server 5189 --bind 127.0.0.1`，访问 http://127.0.0.1:5189/ 。

## 体验
点击租房示例 → 体验示例检索 → 选择至少两篇案例并查看详情 → 对比所选案例 → 切换主要发现、逐案对比、待核对材料 → 预览报告 → 下载 HTML / 打印 PDF。

案例全部虚构，无真实案号或法院。检索与分析为 4 秒模拟动画。输入和文件不会上传，文件仅记录名称。示例固定为租房场景，不依据任意输入生成结论。页面操作保存在当前标签页 sessionStorage。刷新仍可查看选择；无后端业务持久化。

## 设计约定
延续现有品牌：深绿 #176e63、文字 #193e3a、背景 #f5f7f6、淡绿 #edf4f0、边框 #dce5e1、差异提示 #88622c。界面用苹方/微软雅黑，案例标题和报告标题用宋体。入口集中输入，结果采用案例列表与详情双栏，报告采用纸张与导出栏。小屏改为纵向排列，表格内部滚动。尊重减少动态效果设置。

资料检索的 Portfolio Grid 建议不适合本任务，未采用；主从布局检索无匹配，使用技能通用可访问性指导及项目既有设计。
