# 法小智全站蓝白设计预览

范围：法律问答、类案检索、合同审查、法规查找、我的、设置、登录。所有页面为独立设计预览，正式应用不受影响。

用户要求全站不要绿色，参考两张法律产品截图。配色采用白色、浅灰、黑灰文字，蓝色用于操作与选中状态；类案结果使用筛选栏与结果列表，合同使用上传区与原文/建议双栏。图标延续项目现有线性 SVG，不复制参考站品牌。

动效：本地 GSAP（来自项目已安装版本），页面短距离进入、星形图标入场、折叠内容高度过渡；CSS 负责侧栏布局收放和点击反馈。支持系统减少动态效果与预览设置中的关闭按钮。

启动：在项目根目录运行 `python3 -m http.server 5190 --bind 127.0.0.1 --directory previews/site-refresh`，访问 http://127.0.0.1:5190/#ask 。

体验：问答点示例后提交；类案点示例后模拟检索，可筛选、选案、对比及下载 HTML 示例报告；合同用示例合同进入审查流程；法规仅演示输入和结果版式；我的显示固定演示记录；登录不发送凭据。

边界：不调用模型或任何检索服务，不上传或读取所选文件。结果均标记虚构。合同采纳按钮仅展示交互反馈，不写入真实合同。界面状态只保留在当前页面内存中。

验证：JS 语法通过；浏览器验证模块切换、示例检索与结果、对比入口、合同示例与立场步骤。桌面及窄屏布局检查。该预览不是正式功能回归或真实法律模型测试。
